# Order Analysis — анализ заказов на Python

## О проекте

Проект предназначен для пакетной обработки файлов с данными о заказах. Программа анализирует входные CSV-файлы, рассчитывает метрики и формирует отчёт с результатами обработки.

Проект выполнен в рамках практического задания по Python.

## Возможности

* Пакетная обработка файлов с данными о заказах.
* Фильтрация записей и расчёт метрик.
* Формирование итогового CSV-отчёта.
* Обработка ошибок и ведение журнала.
* Настройка параметров через `config.py`.
* Разделение логики программы на отдельные методы.

## Структура проекта

* `config.py` — настройки программы.
* `OrderAnalyzer` — основной класс анализа заказов.
* `data/` — входные данные.
* `reports/` — отчёты и результаты обработки.
* `order_analysis.ipynb` — Jupyter Notebook с описанием архитектуры, алгоритма и метрик.

*Фактические имена файлов и папок следует сверить с содержимым репозитория.*

## Используемые технологии

* Python
* CSV
* Jupyter Notebook
* Логирование и обработка исключений

## Запуск

1. Установите Python.
2. Скачайте или клонируйте репозиторий.
3. Установите необходимые зависимости, если они предусмотрены проектом.
4. Проверьте настройки в `config.py`.
5. Запустите основной Python-скрипт проекта.

Точное имя запускаемого файла и дополнительные требования определяются структурой проекта.

## Результат

Проект демонстрирует навыки работы с табличными данными, организации Python-кода, пакетной обработки файлов, формирования отчётов и обработки ошибок.
