# Анализ заказов на Python

Учебный проект по обработке данных из CSV-файлов с использованием Python и pandas.

Программа пакетно обрабатывает файлы с данными о заказах, отбирает доставленные заказы, рассчитывает основные показатели и формирует сводный отчёт. Ошибки при обработке отдельных файлов фиксируются в журнале, чтобы сбой одного файла не прерывал обработку остальных.

## Возможности

* Пакетная обработка CSV-файлов из папки `data/`.
* Проверка наличия обязательных столбцов.
* Фильтрация заказов со статусом `Delivered`.
* Расчёт общей выручки, среднего чека и количества заказов.
* Сохранение результатов в сводный CSV-отчёт.
* Логирование ошибок при обработке файлов.
* Обработка файлов по отдельности с продолжением работы при возникновении ошибки.

## Структура проекта

```text
python-order-analysis/
├── data/
│   ├── order_10000.csv
│   ├── order_100000.csv
│   └── order_broken.csv
├── logs/
│   └── errors.log
├── reports/
│   └── summary_report.csv
├── src/
│   └── analyzer.py
├── config.py
├── order_analysis.ipynb
├── requirements.txt
└── run.py
```

## Основные файлы

* **`run.py`** — точка входа в программу. Создаёт анализатор, запускает обработку файлов и выводит итоговую статистику.
* **`config.py`** — содержит пути к папкам, имена файлов и параметры обработки CSV.
* **`src/analyzer.py`** — основная логика: чтение данных, проверка структуры, фильтрация заказов, расчёт показателей, сохранение отчёта и журналирование ошибок.
* **`order_analysis.ipynb`** — Jupyter Notebook с материалами анализа.
* **`requirements.txt`** — список внешних зависимостей проекта.

## Результаты работы

После запуска программа формирует сводный отчёт `reports/summary_report.csv` со следующими показателями:

| Поле            | Описание                              |
| --------------- | ------------------------------------- |
| `file_name`     | Имя обработанного файла               |
| `total_revenue` | Общая выручка по доставленным заказам |
| `avg_check`     | Средний чек                           |
| `orders_count`  | Количество доставленных заказов       |

Информация об ошибках обработки записывается в `logs/errors.log`. В консоль выводятся количество успешно обработанных файлов и количество файлов с ошибками.

## Запуск проекта

Для запуска необходим установленный Python и зависимости из `requirements.txt`.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ray094094/python-order-analysis.git
   cd python-order-analysis
   ```

2. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активируйте окружение в Windows CMD:

   ```cmd
   .venv\Scripts\activate
   ```

4. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Запустите программу:

   ```bash
   python run.py
   ```

**Примечание:** команды приведены для Windows CMD. Запуск необходимо проверить в конкретном окружении; если команда `python` не распознаётся корректно, сначала настройте установку Python.
